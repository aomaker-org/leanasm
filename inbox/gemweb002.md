Wiring a local GGUF prover model into a Lean 4 REPL requires running `llama-server` as a local OpenAI-compatible HTTP endpoint alongside a stateful Lean 4 environment (`leanprover-community/repl` or `Pantograph`) launched inside `formal-conjectures` via `lake env`. A Python orchestrator bridges the two over stdio JSON and local HTTP, managing proof state branching (`proofState` IDs), best-first search, and post-proof verification.

---

### 1. Architecture & Process Topology

```text
+-----------------------------------+       HTTP POST /v1/chat/completions
|  Python Proof-Search Harness      | -------------------------------------> [ llama-server (GGUF) ]
|  (uv / asyncio / Best-First BFS)  | <-------------------------------------   DeepSeek-Prover-V2-7B
+-----------------------------------+       Candidate tactics + logprobs       or Goedel-Prover-V2-8B
          |              ^
   stdin  |              | stdout
 (JSON)   v              | (JSON proofState / goals / errors)
+-----------------------------------+
|  lake env /path/to/repl           |  <-- Inherits formal-conjectures + Mathlib .oleans
+-----------------------------------+

```

* **REPL Choice (`leanprover-community/repl` vs. `Pantograph`):** `leanprover-community/repl` is lightweight, accepts single-line or blank-line-delimited JSON commands over `stdin`/`stdout`, and tracks environment snapshots (`env`) and tactic states (`proofState`) as integer handles. (If you need explicit `have`/`let` goal-branching or `conv`/`calc` mode switching, swap in `Pantograph`.)
* **Model & Quantization Selection:** **DeepSeek-Prover-V2-7B** (`Q4_K_M` ~4.4 GB or `Q8_0` ~7.5 GB) and **Goedel-Prover-V2-8B** (`Q4_K_M`) have mature GGUF conversions and fit comfortably in 8–16 GB of system RAM or VRAM.

### 2. Building the Lean 4 REPL Against `formal-conjectures`

The REPL binary must be compiled with the exact same Lean toolchain version pinned in `formal-conjectures/lean-toolchain` so its `.olean` environment headers match.

```bash
# 1. Inspect the toolchain pinned by formal-conjectures
cd ~/src/formal-conjectures
TOOLCHAIN=$(cat lean-toolchain)
echo "Target toolchain: $TOOLCHAIN"

# 2. Clone and build leanprover-community/repl using that exact toolchain
cd ~/src
git clone https://github.com/leanprover-community/repl.git
cd repl
echo "$TOOLCHAIN" > lean-toolchain
lake build

# 3. Smoke-test the REPL inside the formal-conjectures lake environment
cd ~/src/formal-conjectures
printf '{"cmd": "import FormalConjectures.Util.Answer\n#check @sorryAx"}\n\n' | \
  lake env ~/src/repl/.lake/build/bin/repl

```

Running the REPL via `lake env ~/src/repl/.lake/build/bin/repl` inside `formal-conjectures` injects `LEAN_PATH` with all precompiled Mathlib and `FormalConjecturesUtil` `.olean` artifacts without modifying `formal-conjectures/lakefile.toml`.

### 3. Serving the GGUF Prover via `llama.cpp`

Compile `llama.cpp` from source (avoiding un-audited install scripts) and launch `llama-server` bound strictly to `127.0.0.1`.

```bash
# Build llama.cpp (omit -DGGML_CUDA=ON for CPU/AVX2-only hosts)
cd ~/src
git clone https://github.com/ggml-org/llama.cpp.git
cd llama.cpp
cmake -B build -DGGML_CUDA=ON
cmake --build build --config Release -j "$(nproc)" --target llama-server

# Start the local OpenAI-compatible inference server
./build/bin/llama-server \
  --model /path/to/models/DeepSeek-Prover-V2-7B-Q4_K_M.gguf \
  --host 127.0.0.1 \
  --port 8080 \
  --ctx-size 8192 \
  --threads 4 \
  --flash-attn on

```

* **CPU / Haswell Tuning Note:** On CPU-only AVX2 machines without discrete VRAM, omit `--n-gpu-layers`, set `--threads` to your physical core count (e.g., `-t 4`), and keep `--ctx-size 4096` or `8192` with `--flash-attn on` to keep KV-cache memory pressure low during multi-candidate tactic sampling.
* **Grammar Constrained Decoding (Optional):** If the prover emits verbose Chain-of-Thought prose when you only want single-step tactics, pass a GBNF grammar via `"grammar"` in the `/v1/chat/completions` payload or use a strict prompt template that stops on newline/code-fence boundaries.

### 4. Python Tactic-Search & REPL Harness

Save the following script inside your workspace (e.g., `~/src/formal-conjectures/tools/prover_harness.py`) and run it with `uv run --with httpx python tools/prover_harness.py`. It loads a target conjecture file, extracts the initial `proofState` handle generated by `sorry`, queries `llama-server` for $N$ candidate tactics, and explores the tactic tree using best-first search.

```python
#!/usr/bin/env python3
"""Minimal Lean 4 REPL + llama.cpp tactic-search harness for formal-conjectures."""

import heapq
import json
import re
import subprocess
import sys
from dataclasses import dataclass, field
from pathlib import Path
import httpx

REPL_BIN = Path.home() / "src/repl/.lake/build/bin/repl"
REPO_DIR = Path.home() / "src/formal-conjectures"
LLAMA_URL = "http://127.0.0.1:8080/v1/chat/completions"


class LeanREPL:
    """Manages a stateful lake-env Lean 4 REPL subprocess over JSON stdio."""

    def __init__(self, repo_dir: Path, repl_bin: Path) -> None:
        self.proc = subprocess.Popen(
            ["lake", "env", str(repl_bin)],
            cwd=repo_dir,
            stdin=subprocess.PIPE,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
            text=True,
            bufsize=1,
        )

    def send(self, payload: dict) -> dict:
        assert self.proc.stdin and self.proc.stdout
        # REPL expects JSON followed by a blank line
        self.proc.stdin.write(json.dumps(payload) + "\n\n")
        self.proc.stdin.flush()

        lines: list[str] = []
        while True:
            line = self.proc.stdout.readline()
            if not line:
                err = self.proc.stderr.read() if self.proc.stderr else ""
                raise RuntimeError(f"Lean REPL exited unexpectedly:\n{err}")
            if line.strip() == "":
                if lines:
                    break
                continue
            lines.append(line)
        return json.loads("".join(lines))

    def close(self) -> None:
        self.proc.terminate()
        self.proc.wait(timeout=5)


def sample_tactics(goal_state: str, n_candidates: int = 4) -> list[tuple[str, float]]:
    """Query local llama-server for candidate Lean 4 tactics."""
    prompt = (
        "You are a Lean 4 theorem prover using Mathlib. Given the current tactic "
        "state, output ONLY the next single Lean 4 tactic (no prose, no markdown "
        "fences, no 'by').\n\n"
        f"Tactic state:\n{goal_state}\n\nNext tactic:"
    )
    resp = httpx.post(
        LLAMA_URL,
        json={
            "model": "local-prover",
            "messages": [{"role": "user", "content": prompt}],
            "temperature": 0.7,
            "max_tokens": 96,
            "n": n_candidates,
            "stop": ["\n\n", "```"],
        },
        timeout=60.0,
    )
    resp.raise_for_status()
    data = resp.json()

    seen: set[str] = set()
    candidates: list[tuple[str, float]] = []
    for idx, choice in enumerate(data["choices"]):
        raw = choice["message"]["content"].strip()
        # Strip accidental markdown fences or leading bullets
        tactic = re.sub(r"^```(?:lean4?)?\s*|\s*```$", "", raw).strip()
        tactic = tactic.splitlines()[0].strip() if tactic else ""
        if tactic and tactic not in seen and "sorry" not in tactic and "admit" not in tactic:
            seen.add(tactic)
            # Rank proxy when logprobs are omitted
            candidates.append((tactic, float(idx)))
    return candidates


@dataclass(order=True)
class SearchNode:
    priority: float
    proof_state: int = field(compare=False)
    goals: list[str] = field(compare=False)
    tactics: list[str] = field(compare=False)


def prove_file(lean_file: Path, max_expansions: int = 32) -> list[str] | None:
    repl = LeanREPL(REPO_DIR, REPL_BIN)
    try:
        # 1. Load file into REPL; every `sorry` returns a proofState handle + goal
        init_res = repl.send({"path": str(lean_file)})
        sorries = init_res.get("sorries", [])
        if not sorries:
            print("No sorry goals found in target file.", file=sys.stderr)
            return None

        target = sorries[0]
        queue: list[SearchNode] = [
            SearchNode(
                priority=0.0,
                proof_state=target["proofState"],
                goals=[target["goal"]],
                tactics=[],
            )
        ]
        visited_goals: set[str] = {target["goal"]}

        # 2. Best-first search over Lean proofState handles
        for step in range(max_expansions):
            if not queue:
                break
            node = heapq.heappop(queue)
            current_state_str = "\n".join(node.goals)
            print(f"[step {step:02d} | state {node.proof_state}] {current_state_str}")

            for tactic, cost in sample_tactics(current_state_str, n_candidates=4):
                res = repl.send({"tactic": tactic, "proofState": node.proof_state})

                # Reject tactics that emit errors or warnings
                messages = res.get("messages", [])
                if any(m.get("severity") == "error" for m in messages):
                    continue

                new_goals = res.get("goals")
                if new_goals is None:
                    continue

                trail = [*node.tactics, tactic]
                if len(new_goals) == 0:
                    return trail  # All goals closed!

                goal_sig = "\n".join(new_goals)
                if goal_sig not in visited_goals:
                    visited_goals.add(goal_sig)
                    heapq.heappush(
                        queue,
                        SearchNode(
                            priority=node.priority + 1.0 + cost * 0.25,
                            proof_state=res["proofState"],
                            goals=new_goals,
                            tactics=trail,
                        ),
                    )
        return None
    finally:
        repl.close()


if __name__ == "__main__":
    target_path = Path(sys.argv[1]) if len(sys.argv) > 1 else REPO_DIR / "FormalConjectures/ErdosProblems/1.lean"
    proof = prove_file(target_path)
    if proof:
        print("\n=== CANDIDATE PROOF FOUND ===")
        print("\n".join(f"  {t}" for t in proof))
    else:
        print("\nSearch budget exhausted without closing all goals.")

```

### 5. Key Operational Details & Kernel Verification

1. **Immutable Branching via `proofState`:** Every tactic response from `leanprover-community/repl` returns a fresh integer `proofState` without mutating earlier states. Reusing an earlier `proofState` ID automatically backtracks the proof tree with zero re-elaboration overhead.
2. **Whole-Proof vs. Step-by-Step Mode:** Models like **DeepSeek-Prover-V2** and **Goedel-Prover-V2** are trained heavily on whole-proof generation with `<think>...</think>` blocks. To test whole proofs instead of single tactics, extract the fenced ````lean4` block from the model response and submit it directly via `repl.send({"cmd": full_theorem_with_proof})`—if `"messages"` contains no errors and `"sorries"` is empty, the entire proof elaborated cleanly.
3. **Mandatory Post-Search Audit:** Because `leanprover-community/repl` checks tactics interactively inside a `sorry` context, always splice any discovered tactic sequence back into a standalone `.lean` file and verify it with `lake env lean <file.lean>` plus `#print axioms <theorem_name>` to confirm only `[propext, Classical.choice, Quot.sound]` appear.
